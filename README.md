# Ferretería Valdivia - Sistema Web ASP.NET Core MVC

Sistema integral de gestión para ferretería desarrollado con ASP.NET Core MVC, Entity Framework Core y MariaDB (compatible con entorno local nativo).

## Requisitos previos
- Tener instalado [.NET SDK](https://dotnet.microsoft.com/) (versión 8.0 o superior).
- Tener instalado y corriendo un servidor de **MariaDB** de forma local (o mediante contenedor Docker).
